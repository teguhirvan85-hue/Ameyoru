# Ameyoru 雨夜

A rainy night in Hoshimi, a small Japanese town, built with three.js: walk the streets and the covered arcade,
step into the shops, ride the train to Tsukino, drive along the expressway, take the lift up the Sky Tower.

**Play:** https://teguhirvan85-hue.github.io/Ameyoru/ (desktop browser recommended; it loads about 450 MB the first time)

Run it locally: `node server.js` → http://localhost:5180

Made with love for Desy Ika ♡ (her flower café is in the arcade).

Models, textures, sounds and animations come from Poly Haven, Sketchfab, Poly Pizza, VRoid, Freesound and Mixamo;
see [assets/CREDITS.md](assets/CREDITS.md) for every source and licence.
